Connect agents

Point any AutoClaw agent (or a curl in a loop) at the event API. Every event is persisted to events/*.jsonl.

curl -X POST http://localhost:4826/api/event \
  -H 'content-type: application/json' \
  -d '{
    "type": "agent_start",
    "agent": "refactorer",
    "task": "flatten src/utils.js"
  }'

Event types:

  • agent_start — put agent on the roster
  • file_edit — agent touched a path
  • thought — internal monologue line
  • bark — personality line for the screen
  • test_run — test suite status
  • conflict — two agents, one file
  • merge — work landed
  • agent_done — operator signed off

Or use the helper:

node cli.js bark refactorer "this function is 400 lines. I'm not even mad."
node cli.js edit refactorer src/utils.js
